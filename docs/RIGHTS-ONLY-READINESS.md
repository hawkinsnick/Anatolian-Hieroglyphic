# Linear A method parity and rights frontier

The corpus has a complete current digital identity/bibliography spine for 287 eDiAna entries, with 635 typed source edges, 274 bibliographic assertions, 32 explicit object classes and 118 period candidates. It deliberately contains zero canonical physical objects, zero reading assertions and zero expert-verified entries.

eDiAna documents Hawkins 1995/2000 as foundational Empire/Post-Empire corpora, with Post-Empire annotation initially based on ACLT and transliterations adjusted for modern conventions/recent findings, including new Hawkins readings. These layers are therefore source-dependent rather than independent epigraphic witnesses.

Method-parity controls now expose source lineage, chronology/identity disagreements, component rights, browser/API/exports and reproducible validation.

The material-growth frontier is direct rights-compatible access to Hawkins/CHLI critical editions, authoritative sign inventories/concordances and object-level evidence sufficient to resolve grouped fragments, aliases and unknown object classes. Protected critical text, facsimiles, sign tables and photographs must not be reconstructed from dependent digital interfaces.

Expert palaeographic, epigraphic, object and chronological adjudication remains downstream scientific review.
