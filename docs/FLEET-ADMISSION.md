# Fleet admission reconciliation

The 0.3.1 research contract is implemented through an adapter that preserves the native corpus schema. `python ai-skill/scripts/fleet_contract.py --write` records all declared authorities, native inputs and licensing files; `python ai-skill/scripts/validate_bundle.py` rejects stale authority hashes and disabled behavioral gates. Run the native test suite as well. Admission requires the master fleet validator and registry update after these checks pass.

No inscription reading, physical identity, source permission, independent review or final scholarly readiness is certified by this software gate. Native exclusions and rights remain controlling.
